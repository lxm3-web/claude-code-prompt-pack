一句話，讓 Claude Code
接力做完五件事

這頁有三樣東西。把【】換成你自己的內容，貼給 Claude Code 就能用。做出來的是第一版，你看過、改過再用。

① 影片那一句的完整版② 把工具接上去③ 五句單項指令

01影片裡那一句（完整版）

影片裡只說了「幫我籌備今年的尾牙」。真正貼給 Claude Code 的是下面這一段，它會照順序接力做完五件事，每一步做完停下來等你確認。不是尾牙也能用：春酒、家庭日、客戶活動，改掉活動名稱即可。

我要籌備【活動名稱，例：今年的尾牙】，預計在【日期範圍】，地點【地點，還沒定就寫待定】。 請照下面的順序做，每一步做完先給我看，我說「繼續」再做下一步： 1. 讀【資料夾】裡的報名名單（Excel），告訴我總人數、葷素各幾人，資料有缺的列出來；再以每桌【人數】人排出桌次表，同部門盡量同桌，存成新的 Excel 檔。 2. 查我的 Google 行事曆，在【日期範圍】挑 3 個我晚上有空的日期給我選。我選定前不要建立行程。 3. 在我的 Notion 建一頁「【活動名稱】籌備清單」，分成「場地與餐點／流程與主持／抽獎與獎品／通知與報到」四區，每項有「要完成的事／期限／負責人（留空）」。 4. 在我的 Canva 做一張邀請卡，要有活動名稱、日期、時間、地點、回覆期限，尺寸【例：手機直式 9:16】，日期地點用前面我選定的。風格：【從下面「邀請卡的風格怎麼寫」挑一段貼上】。有公司的品牌範本就用【範本名稱】。 5. 用【資料夾】裡今年的活動照片和影片，剪一支【長度，例：2 分鐘】的年度回顧影片，照月份排序，加上月份字卡。配樂我自己另外提供。 限制：我沒提供的資訊（預算、獎品、場地等）一律寫「待補」，不要自己編；不要訂場地、不要寄信、不要寄行事曆邀請、不要對外發布任何東西。

用之前

  • 先做完下面「② 把工具接上去」，否則第 2、3、4 步它做不了。
  • 名單裡用不到的個人資料（身分證字號、電話）先刪掉。
  • 回顧影片用到同事的照片，放映前請確認當事人不介意。
  • 只想做其中幾步，就把不要的那幾行刪掉。
  • 想順便避開主管的會議：在第 2 步後面加一句「也請避開【同事信箱】的忙碌時段」。這需要對方的行事曆對你開放，我們沒有實測過，結果請自己核對。

邀請卡的風格怎麼寫

第 4 步的「風格」一定要填，而且要寫具體。我們實測的結果：只寫「喜氣、簡潔」會拿到紅底金字的大眾範本；只寫「黑底大字」會拿到很空的版面；寫到「背景用什麼、標題用什麼字、資訊怎麼排」才會好看。下面兩段是實測過、可以直接貼的寫法。

精品晚宴風

高級編輯雜誌風。滿版使用一張有氛圍的照片當背景（香檳杯乾杯或宴會廳圓桌的暖色燈光），照片壓暗讓字清楚。中間是很大的白色襯線體標題，標題下方一條細線。下方用整齊的兩欄資訊列。不要卡通圖示、不要大紅大金的傳統花紋、不要漸層光暈。

復古拼貼風

活潑的復古拼貼海報風。米白色紙張質感的底，黑色超粗黑體大標題佔上半部，搭配一塊重點色色塊。中間放一張有手撕紙邊的照片，周圍撒一些彩色紙片。下方用黑色字條列出資訊，每一行像貼上去的紙條。不要傳統紅金喜慶花紋、不要卡通圖示。

做出來不對，直接說哪裡不對（太花、顏色太多、字太小），請它重做。

為什麼要「每一步停下來」
它能一口氣做完，但前一步錯了，後面會跟著錯。等你熟了，再把「每一步先給我看」改成「全部做完再一次給我看」。

02把工具接上 Claude Code

五件工作，Claude Code 接手的方式不一樣。重點是：上一步的結果，它會自己帶到下一步，你不用在五個軟體之間複製貼上。

工作Claude Code 怎麼接手你要做什麼
Excel 排桌次不用連接，它直接讀你資料夾裡的名單，同部門排同桌、吃素的標出來，存成新檔說要什麼，檔案會放在你的資料夾
Google 行事曆找日期接上之後，它能查你的行事曆，挑出你有空的時段給你選連接一次
Notion 列籌備清單接上之後，它能直接在你的 Notion 建頁，待辦一項一項列好、附期限連接一次
Canva 做邀請卡接上之後，它能建立、匯出你的設計，日期地點直接用前面定好的連接一次
剪影片不用連接，它用程式剪接、上字幕、合成說要什麼，把照片和影片放進一個資料夾給它

連接的三個步驟

Notion、Google 行事曆、Canva 各做一次。

  1. 到 claude.ai 的設定，打開「連接器（Connectors）」。
  2. 找到 Notion、Google Calendar 或 Canva，按「連接（Connect）」。
  3. 照畫面登入你的帳號、按同意。回到 Claude Code，輸入 /mcp 確認它出現在清單裡，之後提到它就會去用。
連接之後，Claude 看得到的範圍和你自己的帳號權限一樣。公司帳號請先確認公司是否允許。
第一次剪影片時，Claude Code 可能會請你同意安裝剪接工具，照它說明的步驟同意即可。

03五句單項指令

只想做其中一件時用。挑一個今天要做的工作，複製那一格，把【】換成你的內容，貼給 Claude Code。拿到第一版後，照「交出去前檢查」看過，再用「下一句」請它修改。

每句都交代四件事白話少了會怎樣
背景這是什麼場合、給誰看寫得很通用，不像你公司的東西
任務要它做出什麼它只給建議，不給成品
格式成品長什麼樣（表格、幾頁、幾秒）拿到一大段文字，還要自己整理
限制不知道的不要編、哪些不能動它會自己補上看似合理的假資料

1｜建專案頁（原本開 Notion）

你是活動專案助理。我要辦【活動名稱】，日期是【日期】，參加的人是【對象與人數】，地點在【地點】。 請在我的 Notion 建一頁「【活動名稱】行程表」，排出從現在到活動當天要做的事。（還沒接上 Notion 的話，直接在對話裡給我表格。） 格式：表格，欄位是「日期／要完成的事／負責人／完成的標準」。 限制：負責人先留空白讓我填；我沒提供的資訊不要自己編，改在表格下方列成「需要我確認的事」。
交出去前檢查
  • 日期和星期有沒有對上
  • 有沒有漏掉要提前預約的事（場地、車、餐）
  • 「需要我確認的事」是不是都回答了
下一句：把每件事改成 Notion 的待辦勾選項目，並把這週要做的排在最上面。

2｜做公告海報（原本開 Canva）

你是品牌文案與版面企劃。我要做一張【活動或公告主題】的公告，給【誰看】，貼在【哪裡，例如公司群組、IG、佈告欄】。 請先給我：主標題 3 個版本（每個 12 字以內）、副標一句、必要資訊（時間、地點、怎麼報名）。我選定之後，請在我的 Canva 建立這張設計。（還沒接上 Canva 的話，改給我版面配置建議：哪一塊放在哪裡、誰最大。） 限制：時間地點只用我提供的【時間】【地點】，沒有的寫「待補」；語氣是【例如親切、正式】；風格是【寫具體：背景用什麼、標題用什麼字、資訊怎麼排】。
交出去前檢查
  • 時間、地點、報名方式有沒有寫錯
  • 主標題是不是一眼就知道在講什麼
  • 手機上看，字會不會太小
下一句：我選第 2 個標題。請在 Canva 建立設計，尺寸用【例如 IG 貼文 4:5】，做好給我連結。

3｜剪短影片（原本開剪輯軟體）

你是短影片企劃。我要拍一支【主題】的短影片，長度【秒數】秒，放在【平台】，給【誰看】。 看完希望觀眾記得一件事：【一句話】。 請先寫腳本給我確認。格式：表格，欄位是「秒數／畫面／口白／字幕」。我確認後，用我放在【資料夾】的素材，剪成直式 9:16 的影片，加上字幕。 限制：前 3 秒就要講到重點；口白要像平常講話；不要出現我沒提供的數字或案例。
交出去前檢查
  • 把口白念一遍，卡住的地方就是要改的地方
  • 關掉聲音，只看字幕，看不看得懂
  • 成片從頭播一遍：字幕有沒有錯字、聲音和畫面有沒有對上
下一句：腳本可以。開始剪，做完告訴我檔案在哪，並列出你哪幾段沒有素材可用。
Claude Code 是用程式剪接，不是打開剪輯軟體。成品你一定要從頭看一遍、聽一遍。

4｜整理名單（原本開 Excel）

你是資料整理助理。下面是我收到的【報名回覆／訂單／回報】，格式很亂。 請整理成一個 Excel 檔，存在【資料夾】，欄位是【例如：姓名／部門／葷素／備註】。 限制：原文沒寫的格子留空白，不要猜；重複的人只留一筆，並在表格下方列出你合併了誰；看不懂的內容另外列出來問我。 【把原始內容貼在這裡】
交出去前檢查
  • 總筆數和你手上的人數對不對
  • 抽 3 筆回原文核對
  • 「看不懂的內容」是不是都處理了
下一句：幫我統計【欄位】各有幾人，並列出還沒回覆的人。
貼進去之前，把身分證字號、電話這類不需要的個人資料先刪掉。

5｜排會議（原本開 Google 行事曆）

你是行政助理。我要和【對象】開【會議主題】，長度【分鐘數】分鐘，希望排在【日期範圍】。 請先查我的 Google 行事曆，列出這段期間 3 個我有空的時段給我選。 限制：避開【例如午休 12:00–13:30、週五下午】；我選定之前不要建立行程，也不要寄邀請給任何人。
交出去前檢查
  • 時段有沒有撞到你沒登記在行事曆上的事
  • 日期、星期、時區對不對
  • 邀請對象的名字和信箱有沒有錯
下一句：我選第 2 個時段。請建立行程，標題是【】，先不要寄邀請，建好給我看。

三個通用的下一句

遇到的狀況貼這一句
太長請砍到一半，只留我一定會用到的。
不像我們公司語氣改成【形容詞】，參考這段我們平常的寫法：【貼一段】
不確定它有沒有亂編請把你自己補上、不是我提供的內容標出來。
最後一件事
按送出的永遠是你。Claude Code 交出來的是第一版，對外的每一個數字、名字、日期，都請你自己看過。
